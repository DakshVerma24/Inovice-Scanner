How to use

  1. Select all the invoice PDFs you want to scan.
  2. Pick a format: Raw Text (whatever the QR code encodes, unmodified), Decoded Text (base64/JSON decoded into readable fields — buyer/seller GSTIN, invoice number, etc.), or Excel Sheet (all decoded fields compiled into a downloadable workbook).
  3. Excel downloads automatically once processing finishes; failed files are listed on a separate "Failed" sheet.
